# Nattu logo explorations

The concept sheet in [`nattu-logo-variations.svg`](./nattu-logo-variations.svg)
contains four vector-friendly directions:

1. **Care Cycle** — emphasizes recurring garden care and continuity.
2. **Garden Calendar** — makes the planning feature immediately recognizable.
3. **Sun & Soil** — feels warmer, more regional, and rooted in cultivation.
4. **App Monogram** — a compact `N` and sprout designed for small app icons.

The concepts use the existing product palette: deep garden green (`#1A4A2E`),
harvest gold (`#C8842A`), and warm off-white (`#FBF9F5`). They are exploratory
artwork, not replacements for the production icons in `assets/`.
